# 04 · 安全与隐私边界

本项目定位：**本地单机、个人使用的开发辅助工具**。所有网络通信默认只发生在你自己的机器上。

## 数据流向

```
剪贴板内容 + 主会话最近 ≤60000 字符文本
        │  （经 127.0.0.1:4399 的 prompt_async）
        ▼
你配置的模型服务商（默认 DeepSeek，经 opencode auth 登录的 key）
```

- 讲解请求由你**自己配置的 provider/key** 计费与传输
- 每次触发实际发送量：选中文本 + 主会话背景（默认上限 6 万字符 ≈ 3-4 万 token，可调小）
- 学习会话历史（问答）同样存于本地 opencode 存储，随每次触发作为该会话上下文发送

## 边界清单

| 项 | 说明 |
|---|---|
| **后台服务无鉴权** | `opencode serve` 仅监听 `127.0.0.1`，无密码。本地单机场景可接受（与 TUI 自带 server 同类）。**切勿**改 hostname 为 `0.0.0.0` 暴露局域网——如需远程使用必须设置 `OPENCODE_SERVER_PASSWORD` 并给脚本补认证 |
| **剪贴板误触** | 没有新选区时按 Alt+L，会讲解**上一次**剪贴板内容。讲解窗口会显示实际发送的原文（用户消息），可自查 |
| **机密外发** | 若复制过密码/密钥/内网敏感信息后误按 Alt+L，该文本会随讲解请求发出。习惯建议：敏感内容不进剪贴板、或触发前清空剪贴板 |
| **讲解 agent 只读** | 禁用 write / edit / patch / bash / todowrite 五项。实测回复消息不含任何 tool 调用。即便模型“想”改文件也没有可用工具 |
| **主会话零改动** | 学习会话是独立空会话；脚本只读主会话消息；不会 fork、不会向主会话写入任何消息 |
| **state.json** | 只含会话 id 映射，无任何密钥/内容 |
| **浏览器端** | 讲解窗口 = opencode 官方 Web UI（本地服务页面），无第三方站点 |

## 推荐做法

- 触发前留意剪贴板内容
- 定期重置学习线（防背景与历史膨胀，见 02-usage）
- 保持 opencode 与 VS Code 更新；升级 opencode 后跑一次测试套件
- 多人共用电脑时，用系统用户隔离；不需要时删除登录计划任务即可停止常驻服务

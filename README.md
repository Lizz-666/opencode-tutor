# opencode-tutor

**在 opencode 里"哪里不会点哪里"：拖选一段看不懂的 AI 输出，一键让独立讲解会话结合你的对话上下文讲清楚——不污染主会话、不打断当前工作、绝不碰你的文件。**

## 为什么用它

| 痛点 | opencode-tutor 的做法 |
|---|---|
| AI 输出里有看不懂的术语/报错/片段，复制粘贴去提问很割裂 | 鼠标**普通拖选** → 按 **Alt+L**，全程不离开键盘工作流 |
| 提问会污染主会话上下文 / 打断正在进行的生成 | 讲解在**独立会话**并行进行，主会话零改动（AI 输出中也能触发） |
| 新会话没有上下文，解释常答非所问 | 优先使用选区所在消息和相邻问答，按完整消息提供背景；新安装默认上限 12000 字符，已有自定义预算保留 |
| 想自己换讲解模型 | **双层模型配置**，改一处、下次触发自动生效 |
| 多项目、多实例环境不好维护 | 学习线按「主会话」自动记忆，任何项目即开即用，配置全局一份 |
| 学习线堆满会话列表 | 学习线住在**独立目录**（`%LEARN%\lines`），TUI/Web 的项目会话列表天然不含它，也不会混入主会话时间线 |

## 快速开始

### 一键安装（推荐）

```powershell
git clone https://github.com/Lizz-666/opencode-tutor.git
cd opencode-tutor
powershell -ExecutionPolicy Bypass -File install.ps1
```

安装器自动完成：复制脚本 → 开启拖选即复制（环境变量）→ 合并 explain agent → 键位/设置合并并**自动迁移旧版配置**
→ 安装讲解面板扩展（**保留你原有配置，改动前自动备份**）→ 运行体检。幂等设计，重复运行安全。

| 可选参数 | 作用 |
|---|---|
| `-DryRun` | 只显示将要修改什么，不落盘 |
| `-WithPrewarm` | 注册后台服务常驻预热计划任务（登录自启 + 30 分钟保活；消除冷启动时面板等待） |
| `-DisablePrewarm` | 禁用预热任务，保留按需启动 |
| `-ResetAgent` | 明确重置讲解 agent；默认升级只补缺失字段 |
| `-Uninstall` | 撤销仍与安装记录匹配的配置变更，保留用户后续修改和学习数据 |

装完两步收尾：

1. `Ctrl+Shift+P` → **Developer: Reload Window**（加载讲解面板扩展；首次安装建议完全重启 VS Code 让环境变量生效）
2. `Ctrl+Shift+P` → **Toggle Do Not Disturb Mode**（防止通知遮挡讲解窗口）

## 日常使用

```
opencode 聊天界面里看到不懂的内容
        │
        ▼ ① 鼠标普通拖选（松手即自动复制，无需 Ctrl+C）
        ▼ ② 按 Alt+L
        │
        ▼ ③ 编辑器区右侧弹出图形讲解窗口
   "你的原文 → 中文讲解（一句话结论→展开→结合你的项目语境）"
        │
        ▼ ④ 不懂就继续在窗口里打字追问
```

**失败信号**：错误原因直接显示在讲解面板上（剪贴板为空时另有两声提示音）；完整脚本日志见输出通道「opencode-tutor」。

**学习会话说明**：多个主会话时先选择当前来源，当前终端会记住绑定；换到同一终端中的另一个主会话时，用命令面板的「重新选择主会话并讲解」。每个主会话对应一条持久「学习线」，反复复用、互不干扰；换主会话自动换线。
生命周期、重置方法与常见操作见 [02-usage.md](docs/02-usage.md)。

**1.2 新操作**：面板可展开本次原文，查看背景来源与用量，选择简短解释、深入解释或举例，以及相关背景、近期对话或仅选区。准备阶段可取消；发送后可停止当前学习会话的生成。达到默认 40 条消息或 60000 字符历史后，下次 Alt+L 会新建学习会话，旧记录保留。

## 工作原理

讲解由 opencode 自己的 **Web UI** 呈现，宿主是本项目自带的 **VS Code 小扩展**（无 npm 运行时依赖）：
`Alt+L` = `opencodeTutor.open` → 扩展隐身运行 `explain.ps1`（取剪贴板 → 保障后台服务 → 选主会话 →
复用/迁移/重建学习线 → 注入背景 → 异步发送）→ 脚本写就绪标记（本次 invocation + 最终 URL）→
扩展在编辑器右侧的 WebviewPanel 打开该深链，由 OpenCode Web UI 展示流式回复；等待期显示当前步骤，失败直接显示原因，
脚本日志进输出通道「opencode-tutor」。

关键设计：

- **自有扩展取代任务系统 + 内建 Simple Browser** —— 不受 VS Code 内部演进影响（1.137 集成浏览器丢参数、1.138 任务系统静默失效均已实测踩坑）；执行、URL 传递、面板行为全部自控
- **空会话而非 fork** —— 讲解窗口只显示「原文 → 讲解」，主会话历史对模型可见、对界面不可见
- **独立目录根会话** —— 学习线不在项目目录、也不是任何会话的子会话：既不进项目会话列表，也不会被 TUI 内联渲染进主会话时间线
- **只读讲解 agent** —— 禁用 write/edit/patch/bash/todowrite/task 全部写类工具
- **稳定运行** —— 后台服务按需隐藏启动；学习线丢失自动重建；旧版子会话迁移时保留历史；状态更新有跨进程锁和原子备份，不自动删除旧线、不强制结束正在运行的服务
- **不依赖 VS Code 链内剪贴板命令** —— 复制交给 opencode 原生 copy-on-select（规避 VS Code 已知 bug 族）

详见 [03-architecture.md](docs/03-architecture.md)。

## 安全与隐私

- 讲解 agent **只读**，实测回复不含任何工具调用
- 每次触发会把「选区 + 按预算选取的主会话背景」发给**你配置的模型服务商**；选择“仅选区”可关闭主会话背景，本学习会话已有历史仍会参与后续回复
- 后台服务仅监听 `127.0.0.1`，请勿暴露到局域网
- 详见 [04-security-privacy.md](docs/04-security-privacy.md)

## 开发与测试

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests\run.ps1   # 需 opencode 在 PATH；测试数量以输出为准
```

测试用真实 `opencode serve`（随机端口 + 临时目录），测完自清理、零残留。
其中 `install.Tests.ps1` 用**沙箱目录**验证安装/卸载的幂等与往返一致性（不触碰你的真实配置）。
仓库测试可在**本仓库目录直接运行**（兼容扁平与 scripts/ 两种布局）。
